A modular, component-based Match-3 built with Unity, utilizing state machines and service-oriented architecture. Developed following modern software design principles for scalability and maintainability.

Architecture Components:
├── State Management (Game State Machine)
├── Service Layer (Board, Score, Move, UI Services)
├── Board System (Grid, Element, Match Detection)
├── Element Management (Animation, State, Pooling)

Design Patterns Implemented:
