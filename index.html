🧩 Wonder Link Clone - Match-3 Framework

A modular, component-based Match-3 game framework built with Unity, utilizing state machines and service-oriented architecture. Developed following modern software design principles for scalability and maintainability.

Architecture Components:
├── State Management (Game State Machine)
├── Service Layer (Board, Score, Move, UI Services)
├── Board System (Grid, Element, Match Detection)
├── Element Management (Animation, State, Pooling)
├── UI System (State-based UI Management)
└── Data Management (Scriptable Objects)
Unity C# State Machine Object Pooling Service Architecture Design Patterns

Design Patterns Implemented:

  • State Pattern - Game flow management
  • Observer Pattern - Event handling
  • Adapter Pattern - System communication
  • Factory Pattern - Element creation
  • Object Pool Pattern - Resource management
  • Strategy Pattern - Match detection algorithms
